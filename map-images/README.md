# Map Images Folder

This folder contains uploaded map images for the Got Greens Farm interactive map.

## Usage
- Images uploaded through the admin interface are saved here
- The default map (farm-map.jpg) should be in the root directory
- Additional maps can be added here and will be accessible through the admin panel

## File Naming
- Files are automatically named with format: `map_[timestamp]_[original-filename]`
- Example: `map_1714348800000_aerial-view.jpg`
